# 重构，再工程

1. 重构是指在同一抽象级别上转换系统描述形式。
2. 设计恢复是指借助工具从已有程序中抽象出有关数据设计、总体结构设计和过程设计等方面的信息。
3. 逆向工程是分析程序并在比源代码更高抽象层次上建立程序的表示过程。
4. 正向工程是即从“需求一设计一编码一测试一部署”的正向推进，实现软件开发。
5. 再工程是指在逆向工程所获得信息的基础上，修改或重构已有的系统，产生系统的一个新版本。包含逆向工程、新需求的
   考虑过程和正向工程三个步骤，重构现有系统并增加新需求。

# RAID

RAID分为以下8个级别：
(1)RAID 0(无冗余和无校验的数据分块)
(2)RAID 1(磁盘镜像阵列)50%
(3)RAID 2(采用纠错海明码的磁盘阵列)
(4)RAID 3和RAID 4(采用奇偶校验码的磁盘阵列)
(5)RAID 5(无独立校验盘的奇偶校验码磁盘阵列)
(6)RAID 6(具有独立的数据硬盘与两个独立的分布式校验方案)
(7)RAID 7(具有最优化的异步高I/O速率和高数据传输率的磁盘阵列)
(8)RAID 10(高可靠性与高性能的组合)
